# Fixes Applied to the AWS Terraform Project

This package was reviewed against the EEMS Docker release `1.0.0`.

## Application artifact fixes

- Updated EEMS Docker image references from `v1.0` to `1.0.0`.
- Removed any requirement to copy EEMS source code into the AWS project.
- EC2 pulls the immutable application images from Docker Hub.

## Terraform/state fixes

- Removed the account-specific hard-coded Terraform state bucket.
- Main backend uses partial S3 backend configuration; the real bucket is supplied with `-backend-config`.
- Terraform state files and local `.terraform` directories are excluded.
- The provider lock file is kept for reproducible provider versions.

## Database fixes

- RDS PostgreSQL is pinned to supported major version 16 with a current minor default.
- Automatic minor version upgrades are enabled.
- RDS is private and reachable only from the application security group.
- Database passwords are generated by Terraform and stored in Secrets Manager.
- JWT secret is generated and stored in Secrets Manager.
- Demo account passwords are generated and stored in Secrets Manager rather than committed to source control.
- The generated database password uses URI-safe characters so the application `DATABASE_URL` remains valid.

## EC2 bootstrap fixes

- Docker and Nginx are installed automatically.
- EC2 retrieves secrets through its IAM role.
- Backend readiness is checked through `/api/health` before schema/seed operations.
- Nginx proxies `/`, `/api/`, and `/uploads/` correctly.
- Docker Hub image tags are explicit and immutable.
- No SSH access is required; SSM is used for administration.
- Demo account seeding tolerates a concurrent unique-email race when two ASG instances bootstrap together.

## Load balancing fixes

- ALB targets the Nginx port on the private EC2 instances.
- Health checks use `/api/health`.
- When a domain is enabled, HTTP redirects to HTTPS.
- HTTPS uses an ACM certificate validated through Route 53.

## Route 53 / ACM

- Added optional Route 53 hosted zone creation.
- Added DNS-validated ACM certificate.
- Added HTTPS ALB listener.
- Added HTTP → HTTPS redirect.
- Added Route 53 ALB alias record.
- Added Terraform outputs for Route 53 nameservers and application URL.
- GoDaddy remains the registrar; Route 53 becomes authoritative after nameserver delegation.

## Security

- Application and database subnets remain private.
- ALB is the public entry point.
- RDS is not publicly accessible.
- S3 public access is blocked and server-side encryption is enabled.
- Secrets are not stored in `terraform.tfvars`.
